Sobre o MasterCine

Um espaço para descobrir filmes e séries, conhecer novas histórias e organizar o que você deseja assistir.

O projeto

O MasterCine é um catálogo de filmes e séries desenvolvido para reunir informações sobre diferentes títulos em uma única interface. A página inicial apresenta conteúdos populares e categorias; a pesquisa permite encontrar títulos pelo nome; e a página de detalhes reúne informações como sinopse, elenco, trailer e episódios de séries.

Recursos

  • Catálogo dinâmico de filmes e séries.
  • Pesquisa de títulos pelo nome.
  • Informações detalhadas, elenco e trailers.
  • Temporadas e episódios de séries.
  • Lista de favoritos salva no próprio navegador.

Tecnologias

O projeto utiliza HTML5 para estruturar as páginas, CSS3 para a apresentação e responsividade, JavaScript para as interações e a API do TMDB para consultar os dados de filmes e séries. O recurso de favoritos utiliza o armazenamento local do navegador (localStorage).

Os dados de filmes e séries são fornecidos pelo TMDB.

Este produto utiliza a API do TMDB, mas não é endossado ou certificado pelo TMDB.
